# Flask Tutorial: Zero to Hero

This repository contains code for a Flask tutorial, taking you from a basic application to a full-fledged production-ready app.

## Cloning the Repository

To duplicate this repository to your local machine, open your terminal and run:

```bash
git clone https://github.com/Divyam07and10/Flask_TUTORIAL.git
cd Flask_TUTORIAL
```

## Exploring Branches

This repository uses different branches to represent different stages or versions of the application.

To list all available branches:

```bash
git branch -a
```

## Checkout Commands

To work with a specific version of the tutorial, you can switch branches using `git checkout`.

For example, to switch to the `main` branch (if you aren't already on it):

```bash
git checkout main
```

If you see other branches in the `git branch -a` list (such as feature branches or older tutorial states), you can switch to them using:

```bash
git checkout <branch-name>
```
